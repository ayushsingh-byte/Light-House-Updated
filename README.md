

# 🚀 Light House – Modern React Website

A modern, fast, and responsive frontend website built using **React + Vite**, combining the power of **HTML, CSS, and JavaScript** with a clean component-based architecture.
This project is designed for learning, experimentation, and showcasing modern frontend development practices.

---

## ✨ Features

* ⚛️ Built with **React**
* ⚡ Lightning-fast development using **Vite**
* 🎨 Clean and responsive UI with **HTML & CSS**
* 🧩 Modular and reusable components
* 🔥 Hot Module Replacement (HMR)
* 📱 Responsive design for all screen sizes
* 🧹 ESLint configured for code quality

---

## ▶️ How to Run the Project Locally

### 1️⃣ Prerequisites

Make sure **Node.js (v16 or higher)** is installed.

Check using:

```bash
node -v
npm -v
```

---

### 2️⃣ Install Dependencies

Navigate into the project folder:

```bash
cd vite-project
npm install
```

---

### 3️⃣ Start the Development Server

```bash
npm run dev
```

You’ll see output like:

```
Local: http://localhost:5173/
```

---

### 4️⃣ Open in Browser

Open:

```
http://localhost:5173
```

Your website should now be running successfully 🚀

---

## 📦 Build for Production

To generate an optimized production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
